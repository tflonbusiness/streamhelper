- (direction) User requests Dot Field background animation from reactbits.dev on the login page (/ route, LoginPage.tsx).
- (decision) Source component: React Bits DotField (DavidHDev/react-bits) — canvas grid with cursor bulge physics and SVG glow; copy-paste TS+CSS into app, no new npm dependency.
- (decision) Scope limited to guest login route only; dashboard and authenticated shell unchanged.
- (capability) CAP-1: Login page displays full-viewport animated dot-field background behind the existing login card.
- (capability) CAP-2: Dots react to pointer movement with bulge displacement and cursor glow per React Bits DotField defaults.
- (capability) CAP-3: Login card, Kick OAuth button, error alerts, and feature tiles remain fully interactive and readable above the background.
- (capability) CAP-4: Dot-field colors tuned to Caz Agent dark theme (neutral-950 base, brand gold + purple gradient on dots) per login-background.md.
- (constraint) Port DotField to TypeScript; project uses MUI/Emotion, not Tailwind — use companion CSS file, not TW variant.
- (constraint) Background layer is decorative: position fixed/absolute, z-index below PageShell content, pointer-events none on canvas container.
- (constraint) Preserve existing LoginPage layout and copy (English-only per spec-app-english-only); animation is additive only.
- (constraint) Honor prefers-reduced-motion: static dot grid or animation paused when media query matches.
- (constraint) npm run build in app/ must pass; no new runtime dependencies beyond React canvas APIs.
- (decision) Non-goal: DotField on landing page, dashboard, or other routes.
- (decision) Non-goal: User-facing controls to customize dot-field props.
- (decision) Non-goal: Installing @react-bits npm package or shadcn CLI add — vendored component only.
- (assumption) Touch devices without mouse still show ambient dot grid; bulge follows touchmove when pointer events fire.
- (assumption) Default React Bits prop values (dotRadius 1.5, dotSpacing 14, bulgeOnly true, bulgeStrength 67) are acceptable starting point before brand color tuning.
- (question) Should sparkle or waveAmplitude be enabled for extra motion, or keep defaults (both off)?
- (note) Reference URL: https://reactbits.dev/c/backgrounds/dot-field
