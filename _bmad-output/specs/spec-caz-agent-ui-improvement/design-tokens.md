# Design tokens — Caz Agent (shadcn theme)

Palette aligned with [stream-helper](https://github.com/novapointstrix/stream-helper) `WIDGET_THEMES.main` (`src/constants/themes.ts`, `src/index.css`).

`app/` uses shadcn CSS variables in `globals.css` (generated by `shadcn init`, then customized). `landing/` mirrors the same HSL values inline.

## shadcn init defaults

- **Style:** New York
- **Base color:** Slate (semantic tokens overridden below)
- **CSS variables:** enabled
- **Dark mode:** `class` strategy — `<html class="dark">` set in `index.html` or root layout

## Theme customization (dark)

After init, override in `globals.css` `.dark` block. Map shadcn semantic tokens to stream-helper `main`:

| shadcn variable | Product intent | HSL (dark) | Hex ref |
|-----------------|----------------|------------|---------|
| `--background` | Page bg (`bg`) | `240 9.1% 4.3%` | `#0A0A0C` |
| `--card` | Panel surface (`surface`) | `240 7.7% 7.6%` | `#121215` |
| `--popover` | Popover surface | `240 7.7% 7.6%` | `#121215` |
| `--foreground` | Primary text | `0 0% 100%` | `#FFFFFF` |
| `--muted-foreground` | Lead / muted (`textSecondary`) | `217.9 10.6% 64.9%` | `#9CA3AF` |
| `--border` | Panel borders (`border`) | `240 7.5% 13.1%` | `#1F1F24` |
| `--input` | Input border | `240 7.7% 10.2%` | `#18181C` |
| `--primary` | Accent / CTA (`accent`) | `37.7 92.1% 50.2%` | `#F59E0B` |
| `--primary-foreground` | CTA text on amber | `240 9.1% 4.3%` | `#0A0A0C` |
| `--secondary` | Secondary button (`surfaceSecondary`) | `240 7.7% 10.2%` | `#18181C` |
| `--secondary-foreground` | Secondary button text | `0 0% 100%` | `#FFFFFF` |
| `--destructive` | Error alert (`danger`) | `0 84.2% 60.2%` | `#EF4444` |
| `--ring` | Focus ring (`accent`) | `37.7 92.1% 50.2%` | `#F59E0B` |
| `--radius` | Border radius | `0.75rem` | — |

**Success (non-shadcn default):** use `#10B981` (`160.1 84.1% 39.4%`) for success alerts and badges — map via custom `--success` or Tailwind `emerald-500` until shadcn adds a semantic token.

**Primary hover:** darken accent toward `#D97706` (`32.1 94.6% 43.7%`).

Exact HSL decimals may be tuned during implementation; hex references from stream-helper are the contract.

## Typography

shadcn inherits Tailwind defaults. Set in `tailwind.config.ts`:

```ts
fontFamily: {
  sans: ['Inter', 'system-ui', 'sans-serif'],
},
```

Load Inter via Google Fonts in `index.html` or `@fontsource/inter` — same as stream-helper.

## Migration

1. Run `shadcn init` — replaces Vite `index.css` scaffold.
2. Override `.dark` variables per table above (replaces prior slate/blue `#2563eb` palette).
3. Delete `App.css` and its import from `App.tsx` after all pages use shadcn.
4. Remove orphan classes: `.page`, `.panel`, `.form`, `.error`, `.success`, `.badge`, `.account-list`, `.stack`, `.muted`, `.secondary`.
5. Set `class="dark"` on `<html>` in `app/index.html`.

## Landing sync

Copy computed hex equivalents of the shadcn dark theme into `landing/index.html` `<style>` block:

- Page bg: `#0A0A0C`
- Text: `#FFFFFF`; muted: `#9CA3AF`
- CTA button: `background: #F59E0B`, `color: #0A0A0C`, `border-radius: calc(0.75rem - 2px)`
- CTA hover: `#D97706`
